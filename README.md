# 《星屿》Xingyu 🌟

> 哥哥给 12 岁妹妹做的私人成长记录 App，也是一份「数字家书」。
> 妹妹随手记录生活、心情、学习、家人，所有数据用图表让「成长被看见」；哥哥只看得到汇总，永远看不了她的日记原文。

**隐私第一 · 极简操作 · 只鼓励不批评 · 可视化反馈**

---

## ✨ 这是什么

《星屿》是一款**纯前端、本地存储**的单页应用，跑在手机/平板浏览器里，数据全部存在设备本地，不上云、不联网。它帮助妹妹：

- 📝 **随手记录**：心情、吃喝睡玩、学习、生活点滴、家人的事
- 📊 **看见成长**：情绪月历、四叶草健康环、学科气泡图、成长年轮树……
- 💌 **感受陪伴**：哥哥悄悄话、每日一问、每日冷知识、睡前温柔提醒

## 👥 两种角色

| 角色 | 身份 | 能做什么 |
| :-- | :-- | :-- |
| 妹妹（主人） | 日常使用者 | 打开即用，记录一切，看自己全部内容 |
| 哥哥（管理员） | 初始化配置 | 管理员模式录物料 + 看汇总，**看不了日记原文** |

## 🗂️ 五大页面

| Tab | 图标 | 定位 |
| :-- | :-- | :-- |
| 客厅 | 🏠 | 综合仪表盘 + 快捷打卡入口 |
| 点滴 | 🌱 | 成长时间线 + 身体数据 |
| 知识库 | 🌌 | 学科学习 + 常识科普 + 技能学习 |
| 通讯录 | 👤 | 家人/朋友联系人档案 |
| 我的 | ⚙️ | 周报 + 成长年轮树 + 管理员模式 |

## 🛠️ 技术栈

- **Vue 3 + Vite** — 前端框架与构建
- **Vue Router（hash）** — 路由
- **Pinia** — 状态管理
- **Dexie.js** — IndexedDB 本地数据库
- **ECharts + echarts-wordcloud** — 全部图表
- **原生 CSS 变量** — 圆润柔和儿童风格
- **原生 SVG** — 成长年轮树

> 无后端、无云端。技术细节见 [`PROJECT_PLAN.md`](./PROJECT_PLAN.md)。

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开终端提示的地址（默认 http://localhost:5173）
```

手机/平板真机预览：让手机与电脑连同一 WiFi，访问电脑的局域网 IP + 端口（如 `http://192.168.x.x:5173`）。

构建生产版本：

```bash
npm run build
```

## 📤 上传到 GitHub 的步骤

> 沙箱环境无法使用你的 GitHub 账号凭据，因此由你在本地执行以下步骤推送。

```bash
# 1. 进入项目目录
cd D:\agent\AIDome1

# 2. 初始化 git 仓库（如果还没有）
git init

# 3. 添加所有文件
git add .

# 4. 首次提交
git commit -m "init: 星屿项目计划书与文档"

# 5. 在 GitHub 网页新建一个空仓库（不要勾选 README/.gitignore/LICENSE），
#    然后关联远程并推送（把 <用户名>/<仓库名> 换成你的）：
git remote add origin https://github.com/<用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

之后每次开发提交：

```bash
git add .
git commit -m "描述本次改动"
git push
```
